# NLP & Fake News Classification

A hands-on Python project exploring **Natural Language Processing (NLP)** and text classification using a fake news dataset.

## Topics

- Text preprocessing and tokenization
- Stop-word removal and lemmatization
- POS tagging and Named Entity Recognition (NER)
- Sentiment analysis
- Topic modeling
- Bag of Words and TF-IDF
- Machine learning classification and evaluation

## Setup

```bash
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install nltk
python setup_nltk.py
```

The project is practiced in **VS Code** using Python and a virtual environment.
